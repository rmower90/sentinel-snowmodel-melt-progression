# SnowModel and Sentinel-1 Melt Progression Analysis

This repository contains the analysis code used to compare Sentinel-1 synthetic
aperture radar observations with SnowModel simulations and in situ observations
of seasonal snowmelt progression in the Sierra Nevada.

The repository accompanies a manuscript submitted to *Water Resources Research*.

## Repository structure

- `python/figures/` — notebooks used to generate the main manuscript figures.
- `python/supporting_information/` — notebooks used for Supporting Information analyses and figures.
- `python/scripts/` — shared functions for loading data, calculating melt phases, and distributed analyses.
- `python/download/sentinel/` — workflows used to generate Sentinel-1 backscatter products.
- `configs/` — configuration files and dataset paths used by the analysis.
- `data/` — observational and supporting datasets stored directly with the repository.

## Supporting Information

Analysis notebooks used for the Supporting Information are located in
`python/supporting_information/`.

## Data availability

Several observational datasets used by the analysis are included in `data/`.
Other datasets and model outputs are accessed from their original data
repositories or from paths specified in the configuration files. Data sources
and archival locations are described in the manuscript's Open Research section.

Large Sentinel-1 and SnowModel products are not stored directly in this Git
repository.

## Software

Sentinel-1 backscatter products were generated using the workflow archived by
Gagliano and Henderson (2023):

https://doi.org/10.5281/zenodo.7964286

SnowModel simulations were generated using Parallel SnowModel v1.0:

https://doi.org/10.5281/zenodo.11168392

## Reproducibility

The notebooks in `python/figures/` and `python/supporting_information/` document
the analysis used to produce the manuscript and Supporting Information figures.
Some workflows require large model and remote-sensing datasets that are not
stored directly in this repository.

A permanent archival version of this repository will be deposited in a
DOI-generating repository prior to publication.
